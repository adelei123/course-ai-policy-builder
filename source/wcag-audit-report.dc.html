Recommended next steps

  1. Finish the screen-reader check (about 1 hour). Do one full pass with VoiceOver + Safari (Mac, and iOS for the mobile draft sheet) or NVDA + Chrome (Windows) through Limited → Disclosure → Documentation → Result. Radio groups should announce their question and “1 of 4”, question panels should announce expanded or collapsed, and headings should appear in the headings list. Status messages (“Question 2 opened.”, blocker messages, “Copied”, downloads) should be read once without cutting off the focused heading. If they collide, remove the step-change message and re-test.
  2. Check the saved outputs. Save the Canvas policy as PDF from Chrome and open it in Acrobat's Accessibility Checker or PAC. Run Word's accessibility checker on both .docx downloads.
  3. Run an automated scan. Run axe DevTools or WAVE on each of the 15 screens and attach the reports as evidence.
  4. Remove Designer Mode from the production build (it is still reachable with ?review=1 and has a broken “Storyboard ↗” link), then re-export AI Policy Builder.html.
  5. Optional AAA polish. Respect prefers-reduced-motion; add a confirm or undo to “Start fresh”; raise “← Syllabus summary” to 44px; replace auto-advance with a “Next question” button; expand “GenAI” and “UO” on first use.
  6. Document conformance. When the screen-reader check passes, record the results in a VPAT 2.5 (WCAG edition) Accessibility Conformance Report and keep it with the tool and this audit.

Limitations of this audit

This is an expert code review with automated browser checks and limited hands-on testing, not a legal certification. Browser checks ran in Chromium only, with narrow widths simulated by constraining the document width and keyboard input simulated by script. Items marked “Needs manual test” require hands-on checks with a screen reader (NVDA + Chrome, VoiceOver + Safari). Line numbers (L) refer to AI Policy Builder UX.dc.html.

About this report: semantic headings, table header cells with scope, captions, status shown as text (not by color alone), and text contrast of 7:1 or better. The CSV download includes the Round 1, Round 2 and current status for every criterion.
